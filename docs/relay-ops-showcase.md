# Relay | 業務依頼管理

[Relayを開く](https://sakamoto-relay-ops.sukekyu82.chatgpt.site/)

## 作品概要

Webサイト、データ整理、業務運用に関する依頼を作成し、状態と変更履歴を追えるデモです。データやチーム名は架空です。主力3作品に加える補足ショーケースとして掲載しています。

ログイン前は固定された架空サンプルを閲覧できます。ChatGPTでログインすると、本人のデータを保存し、状態を変更して履歴を確認できます。サンプルは本人の保存データにコピーされません。実在の個人情報や社内情報は入力しないでください。

## 設計上の要点

- ChatGPT認証のユーザーIDを所有者キーとして使い、一覧・更新・履歴の各読み出しを本人の依頼に限定
- 作成時の`Idempotency-Key`と正規化本文のハッシュで、同内容の再送を同じ依頼へ結びつけ、異なる内容でのキー再利用を拒否
- 状態変更は`version`照合で競合を検知する楽観的ロック
- D1のSQLiteトリガーで依頼作成・状態変更のイベントを記録し、依頼変更と履歴追加を一つのトランザクションに含める
- 1ユーザー30件、1依頼50回の状態変更まで。依頼の削除機能や自動削除はない
- APIは入力検証、同一オリジンの書き込み境界、バインド値、キャッシュ抑止ヘッダーを利用

## 検証デモの範囲

「検証」欄は固定された架空入力をサーバー側の共通バリデーターに渡すものです。`validation-only`の範囲で、第三者サイトへの攻撃、実データへの操作、脆弱性スキャンや侵入テストは行いません。

## 技術と制約

React 19、TypeScript、Vinext（Next.js App Router互換）、Cloudflare D1、Drizzle ORMを使用します。ソース原本は非公開で、この公開リポジトリには実装コード、認証情報、ユーザーデータを掲載しません。

このデモはセキュリティ認証や第三者による診断を受けた製品ではありません。時間単位のレート制限、負荷試験、自動保持期間、バックアップと復旧の運用も提供していません。イベント履歴は変更の経緯を表示するためのもので、商用監査証跡や改ざん耐性を保証しません。

複数人で共有するチーム、担当者割り当て、管理者・メンバーのロール管理、通知機能は対象外です。導入実績や顧客向け運用実績を示すものではありません。
