# 余白カフェ予約デモ

[デモを開く](https://yohaku-cafe-reservation.sukekyu82.chatgpt.site)

## このデモについて

架空のカフェを題材にした予約フローのデモです。空席などの公開画面はログインなしで閲覧できます。予約の保存、ログイン中の本人の予約一覧、予約取消にはChatGPTへのログインが必要です。

実店舗の予約や営業には使えません。店舗、メニュー、予約データはデモ用であり、実店舗の導入・運営実績を示すものではありません。

## 構成と設計上のポイント

- React 19とTypeScriptで画面を構成
- Vinextを使用。Next.js App Router互換のルーティングを採用
- Cloudflare D1をデータベースに、Drizzle ORM経由でアクセス
- 同じ予約枠への重複予約を防ぐデータベース制約を設定
- 予約の保存・本人の予約一覧・取消は、ログインした利用者に紐づく操作として扱う

## 確認できること

デモでは、空席の閲覧、ログイン後の予約操作、予約内容の確認と取消という利用者向けの流れを確認できます。画面やデータはデモ環境のもので、実店舗の予約受付状況を表しません。

## 制作の進め方

課題設定、要件整理、完成条件の判断、デモの動作確認は本人が行っています。AIコーディングエージェントは設計相談と実装を支援しました。この説明は作品の構成を示すもので、顧客導入や実店舗での運用実績を主張するものではありません。
