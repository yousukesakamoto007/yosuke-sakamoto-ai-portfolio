# フルリモート求人 日次トリアージ

## 現在の実運用フロー

1. PC起動後に対象職種の求人を低頻度で取得
2. リモート区分、勤務地、経験条件、研修形態、雇用形態を判定
3. 初見の会社、既知会社の別求人、再掲を履歴から分類
4. 未経験OK、経験者向け・要否不明、保留、除外へ整理
5. 応募済み企業を別枠で追跡
6. HTMLの日次レポートを生成
7. 応募フォームへの入力を補助し、最終送信前で停止

## 公開版について

`index.html` は、現在の操作と判断フローを匿名データで再現したデモです。実在求人、取得処理、個人情報、認証情報は含みません。

## 設計判断

- 求人IDだけでなく会社名・求人名の指紋で再掲を判定
- 情報不足を即除外せず「要確認」として人へ戻す
- 応募の最終送信、外部サイト、CAPTCHA、未知の質問は自動化しない
- 公開デモと個人用の実運用データを分離
