# FX Trade Analytics

FXの取引履歴CSVをブラウザ上で読み込み、損益・勝率・最大ドローダウン・月次損益・通貨ペア別成績を可視化するポートフォリオアプリです。ページを開くとサンプル30件が自動表示され、CSVを用意しなくてもすぐに操作できます。

## 背景と目的

約12年間のFX専業経験で重視してきた「収益だけでなく、どの程度の下落リスクを伴ったか」「手法や通貨ペアごとに再現性があるか」という視点を、第三者が操作できるWebアプリへ落とし込みました。

完成条件は、次の3点です。

- 取引履歴から主要な収益・リスク指標を同じルールで計算できる
- 期間、通貨ペア、手法を切り替えながら仮説を検証できる
- 実データを外部へ送信せず、ブラウザ内だけで分析できる

## 主な機能

- CSVインポートと必須列の検証
- 総損益、勝率、最大ドローダウン、PF、ペイオフ、平均損益
- 累積損益・ドローダウン・月次損益グラフ
- 通貨ペア別集計
- 通貨ペア・手法・期間フィルタ
- 累計、2025年以前、年別、1～12月を切り替える期間ナビゲーション
- 直近取引一覧
- 取引ごとのエントリー・TP・LC・実決済位置のワンクリック表示
- 実チャート画像の一時添付と価格水準図のPNG保存
- 日本語・英語の代表的なCSV列名への対応
- PC・スマートフォン表示への対応

## 安全性と品質

- 読み込んだCSVはサーバーへ送信せず、端末のブラウザ内だけで処理します。
- CSV由来の文字列はHTMLとして解釈されないようエスケープして表示します。
- 集計ロジックを画面処理から分離し、CSV解析、必須列、PF、最大ドローダウン、通貨ペア集計、期間切替を自動テストしています。
- 5MBを超えるCSVは画面側で受け付けません。

## 対応CSV

推奨カラム:

```csv
date,pair,side,entry,exit,lots,pips,profit,strategy,note,tp,sl,entry_time,exit_time,exit_reason,chart_image
```

日本語カラムにも対応しています。

```csv
日付,通貨ペア,売買,建値,決済値,ロット,損益pips,損益,手法,メモ
```

必須列は `date`（日付）、`pair`（通貨ペア）、`profit`（損益）です。

## ローカルでの確認

